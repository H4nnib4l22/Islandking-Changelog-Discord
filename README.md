# Islandking-Changelog-Discord
Postet automatisch neue Einträge aus dem Islandking-Changelog (https://islandking.ch/changelog) in einen Discord-Channel.  Kein islandking.ch-Login nötig – die Changelog-Seite ist eine öffentliche Route, deren Inhalte direkt (unauthentifiziert) im JavaScript der Seite enthalten sind. Das Skript liest sie von dort, ganz ohne Zugangsdaten.
